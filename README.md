# Adam — Developer Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual design and animations
- `script.js` — lightweight scroll reveal and current year

## Deploy
The site is configured for the existing custom domain `adam.is-a-fullstack.dev` through `CNAME`. Enable GitHub Pages for the `main` branch (root) in the repository settings if it is not already enabled.

## Edit
Update project cards and links in `index.html`. No build step or package installation is required.
